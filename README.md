# OpenToonz Anywhere

## Overview

What would it look like if you could have the identical Opentoonz user experience but access it purely via a web browser hosted [Progressive Web App](https://en.wikipedia.org/wiki/Progressive_web_app) (PWA) session. This project's R&D goal is to realize that dream while retaining the best parts of the OpenToonz app-like user interface that we all know and love.

The core concept behind the Opentoonz Anywhere project is to create a next generation web-browser session-operated Opentoonz app that works across mobile, tablets, and portable devices. It will allow the end user to entirely skip the need to install the Opentoonz desktop application locally on a laptop or workstation so artists could try out the software quickly and easily in a low friction way.
