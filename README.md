# OpenToonz Anywhere

## Overview

The core concept behind the Opentoonz Anywhere project is to create a next generation web-browser session-operated Opentoonz app that works across mobile, tablets, and portable devices. Our goal is to realize this dream using [Progressive Web App](https://en.wikipedia.org/wiki/Progressive_web_app) (PWA) technology while retaining the best parts of the Opentoonz app-like user interface that we all know and love.

An upside to a PWA web app approach is the end user can skip the need to install the Opentoonz desktop application locally on a laptop or workstation. This means artists could try out the software quickly and easily in a low friction way, and even run it on a low powered Chromebook laptop.
