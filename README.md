# OpenToonz Anywhere

## Overview

This project hopes to explore what it would look like if you could have the identical “Opentoonz” user experience but access it purely via a web browser hosted [Progressive Web App](https://en.wikipedia.org/wiki/Progressive_web_app) (PWA) session. The goal is to retain the best parts of the OpenToonz app-like user interface and tools that we all know and love.

The core concept behind the Opentoonz Anywhere project is to create a next generation web-browser session-operated Opentoonz app that works across mobile, tablets, and portable devices. This idea allows the end user to entirely skip the need to install the Opentoonz desktop application locally on a laptop or workstation. With a web-based Opentoonz app, artists could try out the software quickly and easily in a low friction way.
